# اختبارات القدرات الكمية

## تسجيل الاسم وسجل المحاولات

يدخل الطالب اسمه الكامل فقط، من دون إنشاء اسم مستخدم أو اختيار كلمة مرور. عند تسليم الاختبار، تُحفظ الدرجة والإجابات وتاريخ التسليم في Google Sheets، وتُربط محاولات الاسم نفسه عبر الاختبارات المنشورة (index.html للاختبار 1، وquiz2.html إلى quiz7.html). لا تستبدل إعادة الاختبار المحاولة السابقة.

تستخدم الصفحات /quiz-sync.js لإرسال التسليم إلى واجهة Vercel في api/quiz.js، التي تحفظ البيانات من خلال تطبيق Google Apps Script الحالي. ينشر Vercel التعديلات تلقائيًا بعد رفعها إلى GitHub.

عند إضافة اختبار، انسخ صفحة موجودة وأبقِ تحميل /quiz-sync.js واستدعاء window.QuizSync.submitAttempt({name, quiz, questions, answers}) عند التسليم.

الدخول بالاسم فقط لا يثبت هوية الطالب: يمكن للطالب كتابة اسم شخص آخر، وقد تتجمع محاولات طالبين لهما الاسم نفسه. اطلب الاسم الكامل وراجع السجل عند الحاجة.
